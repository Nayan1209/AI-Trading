# Design System
**Version:** 0.1 | **Status:** Draft

Professional financial command center: restrained, high-information, low-decoration.

## Tokens
Background, surface, elevated surface, text, muted text, border, success, warning, danger, info, focus.

## Typography
Display, headings, body, captions, numeric/monospace.

## Components
Buttons, inputs, selects, modals, tables, charts, badges, status indicators, metric cards, position cards, trade-plan cards, risk cards, timelines, toasts, confirmations, navigation.

Target WCAG 2.2 AA where practical.
